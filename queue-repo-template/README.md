# SlopeCycle interview queue — PRIVATE

**Keep this repository private.** It briefly holds customer interviews sent from the SlopeCycle Send app.

- Each folder in `submissions/` is one interview waiting to be processed.
- The processor removes each folder once the Google Sheet has been checked and holds everything from it, then clears the history so recordings don't pile up.
- A folder that stays here means something went wrong with it: the Run Log tab in the sheet says what.

Don't edit or add files by hand. Send interviews with the SlopeCycle Send app.
